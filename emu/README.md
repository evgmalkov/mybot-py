# Эмулятор и ввод

Менеджеры запускают и настраивают эмуляторы; основная платформа — MEmu.
`adb_config.py` выбирает ADB, `screenshot_utils.py` снимает кадры в память
и кэширует шаблоны. `zoom_out.py` выполняет симметричный жест масштаба.
`boot_recovery.py` восстанавливает игру и закрывает распознанные поп-апы.

Разрешение и параметры подключения задаются в `config/system.json`.
После изменения UI не добавляйте слепые тапы для закрытия окон: сначала
проверьте соответствующий маркер на свежем ADB-кадре.
