# Рутины деревни

Здесь находятся ресурсы и стены, запрос подкрепления, переключение аккаунтов
и дополнительные действия деревни. `request_troops.py` открывает армию через
`game_ui`, распознаёт актуальную кнопку подкрепления и подтверждает диалог
перед отправкой. Личная информация хранится в игнорируемом `profiles/`.

Переключение и добавление деревень используют `game_ui.open_account_switcher`:
портрет игрока по фиксированной точке (без цвета/уровня ратуши) → Settings →
синяя кнопка смены ID. Меню и кнопка подтверждаются шаблонами; координаты
и маркеры находятся в `config/game_ui.json`. Слоты списка — в `config/accounts.json`.
Защищённый список Supercell ID может отсутствовать на ADB-кадре, который показывает
оставшиеся под ним настройки. Проверка открытия списка не подтверждает личность
выбранного аккаунта.
