# Распознавание

Лёгкое зрение на OpenCV и шаблонах из живой игры 1600×900.
`digit_ocr.py` читает числа; `IsTarget.py` — добычу противника.
`game_ui.py` проверяет состояния и переходы домашнего экрана, меню боя и армии.
Геометрия, пороги и имена маркеров находятся в `config/game_ui.json`.
Проверка маркера учитывает совпадение и яркость: затемнённый фон под диалогом
не считается открытым экраном. `detect_home_base.py` использует этот же механизм.

Модули границ и изометрии обслуживают геометрию высадки и MBR-CSV.
Кадры для отладки сохраняются в игнорируемом `debug/`.
