# strategies/ — стратегии атаки в формате MyBot-MBR (CSV)

Положи сюда `.csv`-файлы стратегий из MyBot-MBR (папка `CSV/Attack/`) — они появятся
в выпадающем списке атак в GUI как **`[CSV] <имя файла>`** и будут исполняться нашим
движком (`attacks/mbr_csv.py`) без переделок.

## Как это работает
- Парсятся секции `NOTE / SIDE / MAKE / DROP / WAIT` (разделитель `|`).
- Имена войск/заклов/героев MBR переводятся в наши табы через справочник
  `NAME_MAP` (`attacks/mbr_csv.py`).
- Стороны (`FRONT-LEFT`, `BACK-RIGHT`, …) проецируются на «алмаз» базы 1600×900.

## Ограничения (честно)
- Геометрия — **аппроксимация** статическим контуром базы (не динамический
  redline MBR). Точки высадки ложатся на правильное ребро; при необходимости
  подстрой апексы `APEX_*` / `TILE_PX` в `attacks/mbr_csv.py` под свою базу.
- Войска без нашей иконки/таба (маги, гиганты, валькирии, лечка и т.п.)
  **пропускаются с логом** — поддерживается то, для чего есть шаблоны
  (драконы, э-драконы, шары, осада, герои, rage/freeze). Покрытие растёт по мере
  добавления шаблонов войск.

Свои `.csv` в этой папке в репозиторий не коммитятся (`.gitignore`).
