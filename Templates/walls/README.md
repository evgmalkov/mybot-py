# Templates/walls/ — эталоны для апгрейда стен

## Детект уровня стены (актуальный) — `level_text/`
`Templates/walls/level_text/<N>.png` — бинарная маска ЧИСЛА уровня из подписи
**«Wall (Level N)»** над нижней панелью апгрейда. Используется в
[`home_routine.py`](../../villages/home_routine.py) `read_wall_level()`:

- изолируем кремовый текст подписи → бинарная маска, матчим шаблон числа каждого уровня в ROI
  строки (matchTemplate ловит сдвиг центрированного текста);
- лучший уровень → сравниваем с диапазоном GUI (`wall_level_from`/`wall_level_to`):
  апгрейд ТОЛЬКО если `from <= уровень < to`, иначе стену пропускаем.

Игровой шрифт подписи не берётся `digit_ocr` (кремовый, с обводкой), поэтому держим отдельные
пер-уровневые шаблоны числа. Сейчас есть **L13–L19** (1600×900, стиль CoC). Для нового уровня —
переснять число из живой панели (открыть забор → подпись «Wall (Level N)» вверху).

## Свотчи внешнего вида — `<N>/Validate_Upgrade/verify_wall_level.png`
Старые свотчи цвета стены по уровням (8–18). В текущем флоу **не используются** (детект уровня —
по подписи, детект панели — по иконкам ресурса `wall_upgrade_gold/elixir.png`), оставлены как
референс. Не путать с `level_text/` — они сняты с другого элемента и с панелью не совпадают.
