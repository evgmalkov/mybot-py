# Настройки

JSON-файлы содержат настраиваемые значения; логика остаётся в Python.

- `game_ui.json`: разрешение, маркеры экранов, координаты переходов, области
  добычи и результата, распознавание и смещение боевой панели.
- `farming.json`: полнота хранилищ, награды, боевой интерфейс и поп-апы.
- `army.json`, `heroes.json`: состав заклинаний и способности героев.
- `antiban.json`: задержки, высадка и ускорение боя.
- `system.json`: эмуляторы, разрешение, таймауты и отладка.
- `wall_*.json`: распознавание и цены стен.
- `mbr_*.json`, `field_iso.json`: геометрия и стратегии MBR.
- `accounts.json`: настройки переключения аккаунтов.

`bots_layout.json` — личное состояние GUI, исключённое из Git.
Координаты интерфейса откалиброваны для английской игры на MEmu, 1600×900.
