# Ядро

`main.py` выполняет подготовку дома, поиск по добыче, атаку, обработку награды
и запись статистики. `mods.py` расширяет составы и стратегии, `updater.py`
обновляет приложение. Остальные модули связывают цикл с интерфейсом.

Переходы Home → Battle → Army подтверждаются маркерами `game_ui`.
Неуспешная подготовка или переход прекращают текущий цикл. Координаты HUD,
добычи и итогового бонуса хранятся в `config/`.
