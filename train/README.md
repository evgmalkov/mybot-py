# Подготовка армии

`smart_train.py` проверяет войска, заклинания и осадные машины; при необходимости
пересобирает состав. Заклинания задаются в `config/army.json`.
`quick_train.py` загружает сохранённые рецепты и подтверждает «Use Army Recipe?»,
если замок уже содержит подкрепление. Успех — только после возврата на домашний экран.

Обычная тренировка ищет карточки только в нижней панели выбора и прокручивает
её в обе стороны: секция Squads может скрывать драконов. Параметры поиска,
свайпов и задержки тапов — `config/army.json → picker`. Состояние заклинаний
сохраняется только после успешного добавления и проверки готового состава.
Перед серией тапов карточка должна оставаться на месте в нескольких свежих
кадрах: инерция прокрутки LDPlayer иначе подставляет под тап соседнего юнита.
Таймаут стабилизации отменяет тренировку; параметры ожидания находятся в `picker`.

Вход в армию проходит через проверенные состояния Home → Battle → Edit Army
из `vision/game_ui.py`. После подготовки проверяется готовность армии;
ошибка возвращается в основной цикл и отменяет поиск противника.
Подготовка вызывается перед каждой атакой для обоих режимов: обычный сам
пропускает уже готовый состав, быстрый применяет выбранный рецепт.
Шаблоны выбора и готового состава различаются по масштабу и хранятся отдельно
в `Templates/Smart_Auto_train/`.

Для драконов и шаров остаток меньше стоимости самого маленького юнита
допустим: 350/352 готово, 345/352 требует пополнения. Одна проверка используется
при подготовке и перед атакой; наличие обоих типов войск остаётся обязательным.
Шаблоны готовой осады пересняты для всех девяти доступных типов, включая Sky Wagon.
