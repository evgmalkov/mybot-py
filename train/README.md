# Подготовка армии

`smart_train.py` проверяет войска, заклинания и осадные машины; при необходимости
пересобирает состав. Заклинания задаются в `config/army.json`.
`quick_train.py` загружает сохранённые рецепты.

Вход в армию проходит через проверенные состояния Home → Battle → Edit Army
из `vision/game_ui.py`. После подготовки проверяется готовность армии;
ошибка возвращается в основной цикл и отменяет поиск противника.
Шаблоны выбора и готового состава различаются по масштабу и хранятся отдельно
в `Templates/Smart_Auto_train/`.

Для драконов и шаров остаток меньше стоимости самого маленького юнита
допустим: 350/352 готово, 345/352 требует пополнения. Одна проверка используется
при подготовке и перед атакой; наличие обоих типов войск остаётся обязательным.
Шаблоны готовой осады пересняты для всех девяти доступных типов, включая Sky Wagon.
